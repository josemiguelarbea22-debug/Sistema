# Sistema · Plan Gym

App web personal de entrenamiento con temática de "Sistema". Se instala en el iPhone desde Safari con "Agregar a inicio".

- El progreso se guarda en el teléfono y, al entrar con Google, en una carpeta oculta de Google Drive (`appDataFolder`).
- Al guardar, actualiza el nivel en los eventos del calendario.
- Permisos de Google: `calendar.events` y `drive.appdata`. El repositorio no tiene secretos.
